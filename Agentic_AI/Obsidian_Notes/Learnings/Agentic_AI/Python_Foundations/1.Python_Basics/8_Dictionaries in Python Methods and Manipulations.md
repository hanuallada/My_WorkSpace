Dictionaries are mutable and it is the combination of key, value pairs where key acts as an index and values can be any data type including data structures or a list, set, tuple or even a dictionary as well but key should be single name/any data type but not multiple items and it should be unique key in the defined dictionary. Dictionaries are defined in between curly braces just like sets.
