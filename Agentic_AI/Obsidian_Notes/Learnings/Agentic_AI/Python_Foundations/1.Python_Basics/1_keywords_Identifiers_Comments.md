
**==Keywords==** are reserved words in python and can't use those as variable names, function names or any other identifiers.

Keywords are case sensitive. Example **True and true** are not same in python

**==Identifiers==** are the names given to class, functions, variables and etc. in python. It helps differentiating one entity from another.

- Identifiers can be combination of alpha and numbers
- Identifiers should not start with numbers
- Keywords cannot be used as identifiers
- We cannot use special characters like !,@,#,%, etc. in Identifiers.

==True@=1 or 1True = 1 --> Invalid syntax==
==True1=1 --> Accepted==
